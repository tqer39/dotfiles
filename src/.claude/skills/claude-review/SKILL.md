# Claude の敵対的レビュー

スキル内の `scripts/review.py` を対象リポジトリで実行します。基準は `main` で、任意の Git ref を指定できます。

```bash
python3 /path/to/claude-review/scripts/review.py [基準ブランチ]
```

実際には、このスキルの配置場所から絶対パスを解決してください。
merge-base 以降のコミット差分、ステージ済み・未ステージ・未追跡ファイルをレビューします。
無視されたファイルは対象外です。差分がなければ Claude を呼びません。
実行する Codex が機密情報の有無を差分で確認してから呼び出します。スクリプトは秘密情報を自動検出しません。
基準はローカル ref です。古い `main` を避けるには先に `git fetch origin` し、`origin/main` を明示します。

ログイン済みの Claude Code 2.1.325 以降が必要です。
`--tools Read,Glob,Grep` で組み込みツールを制限し、MCP、hook、プラグインとスラッシュコマンドを無効化します。
個人・プロジェクト設定の `permissions.deny` を維持し、作業ディレクトリ外のファイルツールによる読み取りも禁止します。許可が必要な操作は `dontAsk` で拒否します。
`--allowedTools` だけでは他のツールを禁止できません。書き込みやシェル実行を許可しないでください。

長いレビューも同じプロセスで完了を待ちます。Codex の `exec_command` は `yield_time_ms: 1000` などで起動し、
返った `session_id` を `write_stdin` で待ちます。yield は終了やタイムアウトではありません。
別の実行ツールでも同じ実行 ID を継続し、応答が遅いことを理由に再起動しません。

日本語の指摘ごとに重大度、ファイルと行、問題、根拠を確認します。指摘がなければ「指摘なし」と返ります。
実行失敗や空の出力はレビュー完了と扱いません。
指摘は実装と照合してから修正し、対応しない指摘と理由は PR 本文に記載します。
