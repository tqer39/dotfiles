# ドキュメントの日本語化

依頼文で指定された Markdown を日本語に統一します。
以下のパスは対象リポジトリのルート基準です。
編集前に `docs/rules/documentation.md` があれば読み、規約に従います。
なければ対象リポジトリの規約を確認し、言語別文書を残す必要があればユーザーに確認します。

## 手順

1. 対象と既存の翻訳を読み、内容の差や更新漏れを確認します。
2. 必要な情報を日本語で統合し、言語サフィックスのない `.md` に保存します。
3. 英日別ファイルと相互リンクは作成しません。コマンド、パス、固有名は保持します。
4. ファイル移動に伴うリンク、アンカー、スキル内の参照を更新します。
5. dotfiles で RuleSync の参照を変更した場合は `mise run rules-generate` を実行します。
6. 対象リポジトリの手順に従って Markdown と参照先を検証し、結果を報告します。
   dotfiles では `mise run lint` を使います。
