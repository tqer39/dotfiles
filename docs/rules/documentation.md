# Markdown ドキュメントの規約

- このリポジトリの Markdown は、本文・見出し・説明を日本語で定義します。
- ファイル名は通常の `.md` とし、`.ja.md` や `.en.md` など言語別のサフィックスを付けません。
  日本語版と英語版を並行管理せず、1つの正本に統合します。
- コマンド、設定キー、コード、パス、固有名、引用元の原文は、意味を保つため原表記を使用できます。
  他リポジトリや過去の記録に含まれるパスは、実在する参照先を優先してください。
- 英日両方の文書がある場合は、内容と更新状況を比較して必要な情報を日本語で統合します。
  名前を変更したら、リンク・アンカー・スキル・生成元からの参照も更新します。
- `docs/rules/` をルールの正本とし、RuleSync の生成物は正本を読むよう指示します。
  正本の本文を生成物やスキルへ複製しません。
- `AGENTS.md` は直接編集せず、参照の変更は `.rulesync/rules/overview.md` に反映します。
  `mise run rules-generate` で再生成し、既存の `CLAUDE.md` リンクも確認します。
- `mise run lint` を実行し、相対リンクも確認します。
  新規ファイルが検査対象に含まれていることも確認してください。
